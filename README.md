# 玄机 · Xuanji

东西方综合民俗文化娱乐小站，三馆全图：**东方馆**十五件套（黄历、一签、周易、梅花、六爻、择日、八字、称骨、合婚、犯太岁、解梦、飞星、紫微、奇门），**西方馆**五件（星座运势、今日塔罗、生命灵数、卢恩符文、答案之书），**心智馆**三件（16 型人格、大五人格、霍兰德职业兴趣）。
核心由 Rust 编写并编译为 WebAssembly，全部计算在浏览器本地完成；
历法结果与经典黄历库逐项核对一致，心智馆量表与解读均如实标注来源。

## 功能一览

| 功能 | 说明 |
|---|---|
| 今日黄历 | 农历、干支、生肖、每日宜忌、值神、星宿、冲煞、财神/喜神/福神方位、彭祖百忌、节气 |
| 任意日期查询 | 黄历可查询 1900–2100 年任意一天，一键回到今天 |
| 今日一签 | 100 首签诗配原创解签（以原创为主，个别化用古典诗词）；以日期为种子，同一天同一签 |
| 周易抽卦 | 金钱卦摇卦：本卦、变爻、之卦全套呈现；经文为《周易》原文，大意为原创白话 |
| 梅花易数 | 时间起卦：以当下农历年月日时成卦，给出动爻、变卦与体用生克断语 |
| 六爻 | 摇卦装卦：卦宫、世应、纳甲、六亲、六神、旬空与变卦装卦（断卦不在范围） |
| 星座运势 | 按生日定星座，每日综合/爱情/事业/财运与幸运色、幸运数字（西方馆） |
| 今日塔罗 | 22 张大阿卡纳每日一抽（含正/逆位），另可随手抽；牌义原创（西方馆） |
| 生命灵数 | 生命路径数/生日数/态度数/个人年数，保留大师数 11/22；解读原创（西方馆） |
| 卢恩符文 | 古弗萨克 24 卢恩：今日一卢恩与三卢恩（过去/现在/未来）；解读原创（西方馆） |
| 答案之书 | 100 条原创答案，心里想好问题，翻开即答（西方馆） |
| 16 型人格 | 48 道原创题、四维偏好计分、16 型原创文案；非官方测评（心智馆） |
| 大五人格 | IPIP 50 题大五量表（公有领域条目，本站翻译），五维分数与分档解读（心智馆） |
| 霍兰德职业兴趣 | 48 道原创题，RIASEC 六型分数与兴趣代码、对口职业方向（心智馆） |
| 分享图 | 黄历图、签文图在浏览器本地生成，可下载或长按保存 |
| 八字排盘 | 输入出生日期、时间与性别，排出四柱（干支、藏干、十神、纳音、长生、神煞）、五行分布、胎元/命宫/身宫与八步大运 |
| 万事择日 | 按区间筛选「宜」某事项（嫁娶/出行/移徙/开市等 18 种）的日子，可避开冲本人生肖的日期 |
| 犯太岁 | 按年份与生肖查值 / 冲 / 刑 / 害 / 破，附全年犯太岁名单 |
| 称骨 | 袁天罡称骨歌：年/月/日/时四项骨重相加，对照 51 首传统歌诀（通行本） |
| 合婚 | 生肖配对、纳音五行、日主天干三项民间简法合参，给出契合分数与说明 |
| 解梦 | 116 条本站原创梦境词条，可按关键词搜索、按分类浏览 |
| 九宫飞星 | 流年紫白飞星盘：九宫方位吉凶与九星星性；2025 全盘与两处独立来源逐宫核对一致 |
| 紫微斗数 | 完整十二宫命盘：十四主星与主要辅星、庙旺亮度、四化、大限；可叠加任意年份流年（流年命宫、流年十二宫、流年四化）；安星与流年均与 iztro 逐盘核对 |
| 奇门遁甲 | 时家拆补转盘排盘：地/天/人/神四盘、旬空、驿马；与开源引擎 qimen-rs 八个时刻全盘逐宫核对一致（断局不在范围） |

玩法细节与常见问题见 [使用说明](docs/使用说明.md)。

## 快速开始

**使用者**：直接打开上面的在线地址即可，全部功能免费。

**开发者**：

```sh
rustup target add wasm32-unknown-unknown
cd core && cargo run --release   # 核心自检：命令行演示四件套
cd ../web && cargo build --release --target wasm32-unknown-unknown
wasm-bindgen target/wasm32-unknown-unknown/release/xuanji_web.wasm \
  --out-dir ../pkg --target web   # 生成页面用的 JS/WASM 包
```

架构、验证方法、内容库格式与发布流程见 [开发文档](docs/开发文档.md)。

## 项目结构

| 路径 | 内容 |
|---|---|
| `core/` | Rust 核心库（每体系一个模块文件 + 共用层，见架构文档） |
| `web/` | Rust → WebAssembly 绑定层（每体系一个绑定文件，JSON 接口） |
| `content/` | 内容库：签诗、答案、解梦词条（JSON，按体系分文件） |
| `index.html`、`app.js`、`js/` + `pkg/` | 页面（编排器 + 每功能一个模块）与编译产物（GitHub Pages 根目录） |
| `docs/` | 使用说明、开发文档、架构文档 |

## 定位与路线图

玄机的终局定位是**三馆全图**的民俗文化娱乐小站（5.0.0 拍板）：
东方馆做全，西方馆、心智馆逐馆回归并补齐，答案之书归西方馆。
当前进度：

- **东方馆（十五件套，已封顶）**：今日黄历（含时辰吉凶）、今日一签、
  周易抽卦、梅花易数、六爻、万事择日、八字排盘、称骨、合婚、犯太岁、
  解梦、九宫飞星、紫微斗数、奇门遁甲
- **西方馆（五件，已上线）**：星座运势、今日塔罗、生命灵数、卢恩符文、
  答案之书（自东方馆迁入）
- **心智馆（三件，已上线）**：16 型人格、大五人格（IPIP 量表）、
  霍兰德职业兴趣
- **待拍板**：西洋星盘（需星历数据，西方馆压轴，单独评估）

历史注记：3.0.0 曾收窄为东方专馆并下线星座运势、今日塔罗、16 型人格，
6.0.0 已按三馆路线在新架构（5.0.0 模块化重构）上全部恢复并补齐。

全部内容坚持原创写作（个别签诗化用古典除外，见更新日志 2.0.2），
全部计算在本机完成，不收集任何数据。
