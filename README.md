东西方综合民俗文化娱乐小站。核心全部由 **Rust** 编写并编译为
WebAssembly，所有计算在访问者的浏览器本地完成，不收集任何数据。

**三馆全图（6.1.0 终局）**：东方馆十五件套、西方馆六件、心智馆三件，
共 24 个功能。历法与排盘结果逐项与权威来源对拍验证（见「验算体系」），
解读文案以本站原创为主，来源如实标注。

**🌐 在线体验：<https://xiaoyu-hue.github.io/xuanji/>**（手机、电脑均可，无需注册与安装）

## 快速开始

**使用者**：打开上面的在线地址即可，全部功能免费，无需注册。

**开发者**（需要 Rust 工具链与 wasm-bindgen-cli）：

```sh
rustup target add wasm32-unknown-unknown

# 1) 核心层原生自检：全部体系的金标准锚点断言（约数分钟）
cd core && cargo run --release

# 2) 构建 WebAssembly 引擎包
cd ../web && cargo build --release --target wasm32-unknown-unknown
wasm-bindgen target/wasm32-unknown-unknown/release/xuanji_web.wasm \
  --out-dir ../pkg --target web

# 3) 本地预览（仓库根目录即站点根目录）
cd .. && python3 -m http.server 8000   # 打开 http://localhost:8000
```

构建细节、内容库格式与发布流程（含防缓存版本参数纪律、模块图
冒烟检查）见 [开发文档](docs/开发文档.md)。

## 架构概述

三层分工，依赖单向向下，详见 [架构文档](docs/架构文档.md)：

```
页面层    index.html / west.html / mind.html（每馆一页）
          编排器 app.js / west.js / mind.js
          js/ 每功能一个模块：独立初始化、独立失败，互不连坐
              │ 只调用绑定，不含算法
接口层    web/ 每体系一个绑定文件：参数转换 + JSON 序列化
              │ 只做转换，不含业务逻辑
核心层    core/ 每体系一个 Rust 模块 + common.rs 共用层
          content/ 内容库按体系分文件，编译期嵌入
```

硬纪律：单文件软上限约 500 行；模块间不互调内部实现，共用代码
只走共用层；页面资源一律带同版本 `?v=` 参数并以 `import.meta.url`
为基准解析路径；长计算必须分段让出主线程。5.0.0 起按此架构运行，
其间两次页面事故（接线漏误、模块误导入）均已写入架构文档附录
作为事故档案。

## 验算体系

每个体系上线前过四道关：① 原生自检（金标准锚点断言）→
② 金标准对拍 → ③ WASM 产物对拍（导出函数与锚点值与原生一致）→
④ 发布后公网逐按钮点验。各体系的金标准：

| 体系 | 金标准 | 验证规模 |
|---|---|---|
| 黄历/八字/择日等历法类 | lunar-javascript（6tail，MIT） | 多日期全字段逐项一致 |
| 紫微斗数（含流年） | iztro 2.6.5（MIT） | 82 盘逐项一致；流年 3 例全对 |
| 奇门遁甲 | qimen-rs 0.2.1（MIT） | 8 个时刻全盘逐宫一致 |
| 西洋星盘 | 瑞士星历 pyswisseph | 5 盘 60 个数值，最大差 0.137° |
| 称骨骨重表 | 三处独立公开来源交叉核对 | 异文一处已裁定并记录 |
| 九宫飞星 | 两处独立公开来源 | 2025 全盘逐宫一致 |
| 大五人格 | IPIP 公开条目两处来源 | 题序/因子/24 道反向键逐项核对 |

地基 lunar_rust 的四处移植问题（大运结束年龄、命宫 32 位溢出、
时辰天神漏取模、子时流派口径）均已在核心层绕行并记录在
[开发文档](docs/开发文档.md)「已知上游问题」。

## 内容与原创

- **古籍原文**：六十四卦卦辞/爻辞为《周易》公有领域原文
  （繁转简逐项校订）；称骨歌诀为传统通行本。
- **本站原创**：全部解签、答案、解梦词条、塔罗牌义、卢恩解读、
  灵数解读、星盘短评、人格与兴趣文案、合婚断语、梅花断语。
- **如实标注**：100 首签诗中 12 首化用古典诗词（公有领域），
  已在更新日志 2.0.2 逐首列明；大五量表条目为 IPIP 公有领域
  原文的本站翻译；心智馆量表均为非官方测评，不冒用 MBTI 等
  注册商标与他人文案。

## 项目结构

| 路径 | 内容 |
|---|---|
| `core/` | Rust 核心库：每体系一个模块（最大文件约 270 行）+ `common.rs` 共用层 + 原生自检入口 |
| `web/` | Rust → WebAssembly 绑定层：每体系一个绑定文件，统一 JSON 接口（35 个导出函数） |
| `content/` | 内容库（JSON，按体系分文件）：签诗、答案、解梦、卦象、塔罗、人格题库等 8 个文件 |
| `index.html` / `west.html` / `mind.html` | 三馆页面（东方馆/西方馆/心智馆） |
| `app.js` / `west.js` / `mind.js` + `js/` | 页面编排器与每功能一个页面模块 |
| `pkg/` | wasm-bindgen 生成的引擎包（标记为生成代码，不计入语言统计） |
| `docs/` | 使用说明、开发文档、架构文档 |

## 定位与现状

玄机的终局定位（2026-11-20 拍板）是**三馆全图**的综合民俗文化
娱乐小站，6.1.0 已全部落地：东方馆十五件套封顶、西方馆六件
齐全、心智馆三件齐全，后续以维护与内容打磨为主。

历史注记：3.0.0 曾收窄为东方专馆并下线星座运势、今日塔罗、
16 型人格；5.0.0 完成模块化架构重构；6.0.0 起按三馆路线在
新架构上全部恢复并补齐；6.1.0 西洋星盘压轴上线。
